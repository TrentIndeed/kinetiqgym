# Contributing

**Contributions are closed until the verified release.**

Kinetiq Gym is being built and tested as a physical prototype now. The CAD, build files and software are released together once
the prototype has passed load testing. Until then there is no tested design to contribute to, so this repository does not take
pull requests, design proposals or build reports.

## What you can do now

- **Follow the build:** join the build list at [kinetiqgym.com](https://kinetiqgym.com/#join) for prototype results, design
  changes and the release date. It is also the kit waitlist.
- **Support the project:** contributions to prototype iterations and build support are on the
  [build preview](https://kinetiqgym.com/build#support).
- **Engineering work:** for custom mechatronics, motor-control or prototyping projects, use the
  [project form](https://kinetiqgym.com/work).

## After the verified release

Contributions open with the release: build reports, fixes, adaptations (other motors, batteries, mounts), documentation and
software. This file will then describe how to propose a change and how changes are reviewed. Every change is reviewed by the
maintainer before it reaches `main`.

By contributing, you will agree that your contribution is licensed under the licences in [LICENSE.md](LICENSE.md). The Kinetiq
name and logo are not part of those licences.
