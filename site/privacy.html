Privacy

This site collects as little as it can. It adds no analytics or advertising trackers. Its public pages set no cookies; the private owner inbox uses a secure, eight-hour login cookie. Its fonts load from Google Fonts, which sees the request like any web server does.

The build list

When you join, your email address is stored with the date, the page you joined from, the answer to the optional interest question if you give one, and the country your request came from. It is used only to send Kinetiq Gym build updates and release news. It is not sold or shared. Every email will include a way to unsubscribe.

The project form

Your name, email, organisation (if given) and message are stored so I can reply about your project. They are not used for anything else.

Where it is kept, and removal

These are stored with Cloudflare, which hosts this site. To have your details removed or corrected, send a note through the project form with the email you used, and they will be deleted.

Optional automated feedback

Automated visitors can voluntarily send feedback based on public site information. The message, an optional public agent name and the site page are kept privately for the owner until deleted. No conversation history, credentials or other private information is requested, and claimed agent identities are not verified. Replies are not published and do not subscribe anyone to a list.

The feedback endpoint uses short-lived, hashed network identifiers to limit abuse. Those counters expire after about an hour; request IP addresses are not stored with replies. The private owner inbox can export or delete replies. To request removal, use the project form and identify the reply.
