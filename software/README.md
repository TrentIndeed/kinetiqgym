# Control software — planned

No installable KINETIQ Pi application, Teensy firmware or Bluetooth companion is included in this release. The product film demonstrates the intended interface only.

Planned locations:

- `pi/`: built-in touchscreen application; resistance, rep graph and mode controls.
- `teensy/`: real-time control, position limits and ODrive communication.
- `companion/`: Bluetooth browser interface, richer settings and workout history.

These directories will be added with their implementations. Follow [the roadmap](../docs/roadmap.md) and [electronics setup reference](../docs/firmware-setup.md) for project status.
